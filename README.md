# Sarabjeet Singh | Foreign Legal Consultant

A lightweight static website for Sarabjeet Singh's Arizona foreign legal consulting practice.

## Run locally

From this folder, run:

```sh
python3 -m http.server 4173
```

Then open http://localhost:4173.

## Before launch

Replace both `https://forms.google.com/` links in `index.html` with the published Google Form URL. The site intentionally states that consultations are limited to Indian law and do not include U.S. or Arizona domestic law.
